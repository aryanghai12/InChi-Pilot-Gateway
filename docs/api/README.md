## Regenerating the schema and the frontend types

Do both in the same PR as any API change (AGENTS.md §C5 Definition of Done). Run natively from `backend/` with the virtual environment active. The Docker container cannot write to `docs/`.

```bash
cd backend
python manage.py spectacular --file ../docs/api/openapi.yaml
cd ../frontend
npm run generate-types        # openapi-typescript ../docs/api/openapi.yaml -o src/lib/api/schema.d.ts
```

## Conventions (ARCHITECTURE.md §5)

- Base path `/api/v1/`; workflow actions are POST sub-resources (e.g. `/assessments/{id}/submit/`).
- Session cookie auth with `X-CSRFToken`; no tokens.
- Errors: `{"code", "message", "field_errors", "correlation_id"}`; 401 `not_authenticated`, 403 `permission_denied`, 403 `csrf_failed`, 404 `not_found`, 409 on a `version` conflict.
- Page-number pagination, default page size 25.
